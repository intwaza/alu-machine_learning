# Probability

Common probability distributions implemented from scratch in Python
(no imports), using the approximations pi = 3.1415926536 and
e = 2.7182818285.

## Tasks

| File | Description |
| --- | --- |
| `poisson.py` | `Poisson` class: initialization, PMF, CDF |
| `exponential.py` | `Exponential` class: initialization, PDF, CDF |
| `normal.py` | `Normal` class: initialization, z-score / x-value, PDF, CDF |
| `binomial.py` | `Binomial` class: initialization, PMF, CDF |
