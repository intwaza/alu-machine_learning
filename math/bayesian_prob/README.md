# Bayesian Probability

Bayesian inference for a binomial likelihood, built up step by step:
likelihood, intersection, marginal probability, and posterior.

## Tasks

| File | Description |
| --- | --- |
| `0-likelihood.py` | Likelihood of the data for each hypothetical probability |
| `1-intersection.py` | Intersection of the data with each hypothesis |
| `2-marginal.py` | Marginal probability of obtaining the data |
| `3-posterior.py` | Posterior probability of each hypothesis given the data |
