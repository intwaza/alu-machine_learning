# Multivariate Probability

Mean, covariance, and correlation of a data set, and a multivariate
normal distribution class, implemented with NumPy (without `numpy.cov`).

## Tasks

| File | Description |
| --- | --- |
| `0-mean_cov.py` | Calculate the mean and covariance of a data set |
| `1-correlation.py` | Calculate a correlation matrix from a covariance matrix |
| `multinormal.py` | `MultiNormal` class: initialization and PDF |
