# Linear Algebra

Introductory linear algebra exercises in Python and NumPy: array/matrix
slicing, shape, transpose, element-wise operations, concatenation, and
matrix multiplication.

## Tasks

| File | Description |
| --- | --- |
| `0-slice_me_up.py` | Slice an array |
| `1-trim_me_down.py` | Slice the middle columns of a matrix |
| `2-size_me_please.py` | Calculate the shape of a matrix |
| `3-flip_me_over.py` | Transpose a 2D matrix |
| `4-line_up.py` | Add two arrays element-wise |
| `5-across_the_planes.py` | Add two matrices element-wise |
| `6-howdy_partner.py` | Concatenate two arrays |
| `7-gettin_cozy.py` | Concatenate two matrices along an axis |
| `8-ridin_bareback.py` | Perform matrix multiplication |
| `9-let_the_butcher_slice_it.py` | Slice a NumPy matrix |
| `10-ill_use_my_scale.py` | Calculate the shape of a `numpy.ndarray` |
| `11-the_western_exchange.py` | Transpose a `numpy.ndarray` |
| `12-bracin_the_elements.py` | Element-wise add/sub/mul/div with NumPy |
| `13-cats_got_your_tongue.py` | Concatenate `numpy.ndarray`s along an axis |
| `14-saddle_up.py` | Matrix multiplication with NumPy |
